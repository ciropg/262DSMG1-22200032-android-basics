# Codelab: Cómo crear y usar funciones en Kotlin

Aprendí:
- Cómo separar código repetido en una función con `fun`.
- Cómo hacer que una función devuelva un valor (`: String`) en vez de solo imprimir.
- Cómo agregar parámetros a una función y pasarle argumentos.
- Cómo usar argumentos con nombre para reordenarlos sin cambiar el resultado.
- Cómo definir valores predeterminados para parámetros.
