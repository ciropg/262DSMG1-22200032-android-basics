# Codelab: Problemas prácticos - Conceptos básicos de Kotlin

Ejercicios de práctica que integran lo aprendido en los codelabs anteriores:
impresión de mensajes, corrección de errores de sintaxis, plantillas de cadenas,
concatenación vs. suma, funciones con retorno, parámetros predeterminados,
convenciones de nombres, comparación de valores y refactorización de código
repetido en funciones reutilizables.
